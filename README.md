# CSTT — портал по Counter-Strike 2

React + Vite. Данные, вход администратора и картинки — Supabase.

## 1. Supabase (один раз)
1. Создайте проект на supabase.com.
2. SQL Editor → вставьте содержимое `supabase/schema.sql` → Run.
3. Зарегистрируйтесь на самом сайте (кнопка «Войти» → «Регистрация») или создайте пользователя в Authentication → Users.
4. **Права администратора.** В SQL Editor выполните (подставьте свою почту):
```
insert into admins(uid) select id from auth.users where email='ВАША_ПОЧТА';
```
   Только такие аккаунты могут менять данные. Обычные пользователи могут лишь регистрироваться и менять свой ник и аватар.
5. Для простоты отключите подтверждение почты: Authentication → Sign In / Providers → Email → выключите «Confirm email». Иначе при регистрации нужно подтверждать письмо (встроенная почта Supabase ограничена по числу писем).
6. Project Settings → API: скопируйте Project URL и anon public key.

## 2. Запуск
```
cp .env.example .env     # впишите URL и ключ
npm install
npm run dev              # http://localhost:5173
```
Админка: `http://localhost:5173/#/admin`

## 3. Публикация
```
npm run build
```
Содержимое папки `dist` загрузите на любой хостинг (это статика, PHP и Node не нужны). Админка: `ваш-сайт/#/admin`.

## Структура
- `src/lib` — данные (Supabase), переводы RU/EN
- `src/components` — общие компоненты, сетки (`Brackets.js`), оформление новостей (`Md.js`)
- `src/pages` — страницы сайта
- `src/admin` — админ-панель (схема полей, CRUD)
- `src/styles` — CSS
- `supabase/schema.sql` — таблицы и права доступа

## Публикация на GitHub Pages
1. Supabase → SQL Editor → выполнить `supabase/schema.sql` (можно повторно).
2. Репозиторий на GitHub → Settings → Secrets and variables → Actions → добавить `VITE_SUPABASE_URL` и `VITE_SUPABASE_ANON_KEY`.
3. Settings → Pages → Source: **GitHub Actions**.
4. `git push` в ветку `main` — сайт соберётся и опубликуется автоматически (`.github/workflows/deploy.yml`).
5. Supabase → Authentication → URL Configuration → Site URL = адрес сайта на Pages.
- v4.3: Swiss — команды сами переходят в следующий раунд по рекорду (пары по посеву), панель «Прошли / В игре / Выбыли», генератор Swiss учитывает выбранный BO, массовая смена BO стадии; новости — отдельные поля «текст под заголовком» и «основной текст».
